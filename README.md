# Chinedu Promise Mmaduabuchi — Commercial Print & Brand Portfolio

A responsive five-page student portfolio website showcasing professional printing productions, graphic layouts, and commercial branding assets. Built using semantic HTML, external CSS, and vanilla JavaScript.

##  Project Structure

*   `index.html` — Home landing page and personal introduction.
*   `about.html` — Biography, graphics skills, hobbies (gaming/reading), and spoken-introduction placeholder.
*   `projects.html` — Production showcase featuring real-world printing and merchandise case studies.
*   `planner.html` — Interactive academic planner utilizing persistent browser `localStorage`.
*   `contact.html` — Contact details, custom validation, and an active TikTok social link.

## Production Notes & Features

*   **Production Materials:** Project features are compiled case studies tracking live commercial banner prints and custom merchandise workflows rather than simulated academic templates.
*   **Media Assets:** The About page utilizes a dedicated audio media block configured for an upcoming native `assets/audio/introduction.mp3` recording.
*   **Social Routing:** TikTok link connects directly to the client's verified `@prints_with_mindcetworld` production page. 
*   **Forms & Logic:** Contact forms run client-side schema verification matching strict email patterns and numeric strings before prompting a device `mailto:` submission window.
